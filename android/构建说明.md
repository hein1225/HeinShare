# 海因分享（heinshare）安卓版 · 构建说明

本文说明如何在 Linux / macOS / Windows(WSL) 上从源码构建「海因分享」（heinshare）安卓端。

---

## 一、工程结构

```
android/
├── app/                     # 应用壳（Activity、界面、前台服务入口）
│   └── src/main/java/com/heinshare/android/
│       ├── MainActivity.kt      # 主界面：设备列表 / 接收开关 / 日志
│       ├── SendActivity.kt      # 发送界面：SAF 选文件、选设备、发送
│       └── ReceiveActivity.kt   # 接收界面：接受 / 拒绝、进度
├── core/                    # 协议核心（无 Android UI 依赖，纯 Kotlin + java.*）
│   └── src/main/java/com/heinshare/core/
│       ├── Bytes.kt         # 字节序、varint、TLV、帧编解码
│       ├── Crypto.kt        # AES-GCM / ChaCha20-Poly1305 / RSA-OAEP / HMAC
│       ├── Identity.kt      # 本机密钥、device_hash、node_id 派生
│       ├── Protocol.kt      # 信封帧、通道帧、DFile 分包、SETTINGS 档位
│       ├── Channel.kt       # TCP 通道读写
│       ├── Net.kt           # 本机 IPv4 探测
│       ├── Json.kt          # 轻量 JSON
│       ├── Discovery.kt     # UDP 设备发现
│       ├── Sender.kt        # 发送端状态机
│       ├── Receiver.kt      # 接收端状态机
│       ├── ShareHub.kt      # 全局共享状态（设备列表、日志、待确认请求）
│       └── HeinshareService.kt# 前台服务：组播锁 + 发现 + 监听 5684
├── build.gradle.kts         # AGP 8.5.2 / Kotlin 1.9.24
├── settings.gradle.kts      # 阿里云镜像 + 官方源兜底
└── setup-env.sh             # 一键装 JDK 17 + Android SDK（国内镜像）
```

- `core` 是 **Android library 模块**，但协议类（`Bytes` / `Crypto` / `Protocol` / `Channel` /
  `Discovery` / `Sender` / `Receiver`）只用 `java.*` 和 kotlinx.coroutines，不碰界面，
  因此可以在本模块里直接跑 JUnit 单元测试（`src/test/`）。
- `app` 只做界面和系统集成（SAF、前台服务、通知）。

## 二、环境要求

| 组件 | 版本 |
|---|---|
| JDK | 17 |
| Android SDK | platform 34、build-tools 34.0.0、platform-tools |
| Gradle | 8.7（由 wrapper 自动下载） |
| Android Gradle Plugin | 8.5.2 |
| Kotlin | 1.9.24 |
| minSdk / targetSdk | 24 / 34 |

### 2.1 一键安装环境（Linux）

```bash
cd android
bash setup-env.sh
```

脚本做的事（全部走国内镜像）：

| 步骤 | 来源 |
|---|---|
| JDK 17.0.2 | `mirrors.huaweicloud.com/openjdk/17.0.2/` |
| cmdline-tools | `mirrors.cloud.tencent.com/AndroidSDK/` |
| SDK 组件 | 同上（platform-tools / platforms;android-34 / build-tools;34.0.0） |
| Gradle 8.7 | `mirrors.cloud.tencent.com/gradle/`（`gradle-wrapper.properties` 已改写） |

Maven 依赖走阿里云镜像（`settings.gradle.kts`），并保留 google/mavenCentral 兜底。

### 2.2 手动设置环境变量

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
export ANDROID_SDK_ROOT=$ANDROID_HOME
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
```

> 建议把 SDK 与 Gradle 缓存放在**持久目录**，避免环境重建后重复下载。

### 2.3 Windows

用 WSL2 或直接装 Android Studio（自带 JDK 17 与 SDK 34），
然后在 Android Studio 里 `Open` 目录 `android/` 即可；命令行构建方式相同。

## 三、构建

### 3.1 常用命令

```bash
cd android
# 先准备好 JAVA_HOME / ANDROID_HOME（见 2.2）

# 调试包（已用 debug 证书签名，装上就能用）
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk      （包名 com.heinshare.app.debug）

# 正式包（找到密钥库就自动签名）
./gradlew :app:assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk             （包名 com.heinshare.app）

# 跑核心层单元测试（密码学向量、RFC 8439 向量、varint、TLV）
./gradlew :core:testDebugUnitTest
# 报告：core/build/reports/tests/testDebugUnitTest/index.html

# 全部检查
./gradlew :core:test :app:assembleDebug
```

### 3.2 产物

| 构建类型 | 文件 | 包名 | 签名 |
|---|---|---|---|
| debug | `app/build/outputs/apk/debug/app-debug.apk` | `com.heinshare.app.debug` | debug 证书（自动） |
| release | `app/build/outputs/apk/release/app-release.apk` | `com.heinshare.app` | 找到密钥库时自动签名（密钥见第四节）；找不到时退化为未签名包 |

## 四、签名正式包

### 4.1 准备密钥库

release 密钥**不进 git**，由构建者自行保管。目录形如：

```
<你的密钥目录>/
├── hishare-release.jks     # PKCS12，RSA 4096，自签名 SHA384withRSA，别名 hishare，30 年有效期
└── keystore.properties     # Gradle 读取的签名参数
```

准备好后构建即可自动签名：

```bash
cd android && ./gradlew :app:assembleRelease -Phishare.keystore=<你的密钥目录>/keystore.properties
# 产物：app/build/outputs/apk/release/app-release.apk（已签名）
```

验签：

```bash
$ANDROID_HOME/build-tools/34.0.0/apksigner verify --verbose --print-certs \
  app/build/outputs/apk/release/app-release.apk
```

### 4.2 Gradle 是怎么找到密钥的

`app/build.gradle.kts` 按以下顺序找 `keystore.properties`：

| 优先级 | 来源 | 用法 |
|---|---|---|
| 1 | Gradle 属性 | `./gradlew :app:assembleRelease -Phishare.keystore=/path/to/keystore.properties` |
| 2 | 环境变量 | `export HISHARE_KEYSTORE_PROPERTIES=/path/to/keystore.properties` |
| 3 | 默认 | `keystore.properties`（工程根目录或 `android/` 下） |

**找不到就退化为未签名包**（构建不失败，便于在别的机器上先编出包再签名）。

`keystore.properties` 格式：

```properties
storeFile=/path/to/hishare-release.jks
storePassword=***
keyAlias=hishare
keyPassword=***
```

### 4.3 另建一把自己的密钥（自测用）

```bash
keytool -genkeypair -v \
  -keystore my-release.jks -storetype PKCS12 \
  -alias myalias -keyalg RSA -keysize 4096 -validity 10950 \
  -dname "CN=Your Name, O=Your Org, C=CN"
```

写一份 `keystore.properties`，然后：

```bash
HISHARE_KEYSTORE_PROPERTIES=$PWD/my-release.properties ./gradlew :app:assembleRelease
```

> ⚠️ release 密钥一旦丢失，**已安装的用户就再也装不上升级包**（Android 要求同签名）。
> 密钥务必单独备份。

## 五、安装到设备

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
# 或正式包
adb install -r app-release.apk
```

安装后打开 App，**打开「接收文件」开关**（会申请通知权限），即可开始发现设备。

## 六、测试向量

`core/src/test/resources/crypto_vectors.json` 由 Python `cryptography`（43.0.0）生成，覆盖：

| 用例 | 内容 |
|---|---|
| `aes_gcm` | AES-256-GCM，12 字节 nonce，带 AAD |
| `aes_gcm16` | AES-256-GCM，16 字节 nonce，无 AAD |
| `chacha` | ChaCha20-Poly1305，12 字节 nonce，带 AAD |
| `oaep` | RSA-2048 OAEP（SHA-256 摘要 + SHA-1 MGF1）的私钥/公钥/明文/密文 |

另外 `ChaChaRfc8439Test` 直接使用 RFC 8439 §2.8.2 的官方向量，
与 Rust 版 `src/src/chacha.rs` 里的 `rfc8439_aead_vector` 用例一一对应，
保证安卓端和 Windows 端在 Apple 通道上算出的密文与校验标签完全一致。

## 七、常见构建问题

| 现象 | 处理 |
|---|---|
| `SDK location not found` | `export ANDROID_HOME=/path/to/android-sdk` |
| `Failed to find Build Tools revision 34.0.0` | `sdkmanager "build-tools;34.0.0"` |
| Gradle 下载慢/超时 | 确认 `gradle-wrapper.properties` 指向腾讯云镜像；依赖走阿里云 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 设备上已有同包名不同签名版本，先卸载 |
| 中文注释乱码 | 源文件统一 UTF-8；Gradle 默认按 UTF-8 读 Kotlin 源，无需额外配置 |
