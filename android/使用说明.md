# 海因分享（heinshare）安卓版 · 使用说明

在 Android 手机 / 平板上，直接和 **鸿蒙手机、鸿蒙 7、iPad / iPhone** 互传文件。

这是「海因分享」（heinshare）的安卓移植版：与 Windows 版同一套协议、同一个发现机制，
只是把「电脑」换成了「安卓设备」，并且**两个方向都能发**：

- 安卓 → 对端：选文件 / 选文件夹，发给华为手机、鸿蒙平板、iPad / iPhone
- 对端 → 安卓：对方发起分享，安卓这边确认后落盘

> 这是一个**第三方互操作性实现**，与华为、苹果公司没有任何隶属或合作关系。
> 名称仅用于说明它能和谁互通。

## 一、开始之前

### 1.1 对端要做什么

| 对端 | 需要做的 |
|---|---|
| 鸿蒙手机 / 鸿蒙 7 | 打开「华为分享」或「鸿蒙星河互联」，停在**等待接收**的页面 |
| iPad / iPhone | 打开「鸿蒙星河互联」App，停在**接收**页面 |
| Windows 电脑 | 运行 Windows 版 HiShare（`bin\hishare.exe`），停在监听状态 |

对端在**亮屏且已登录同账号**时可能不开分享页也能被发现，但首次连接建议把页面打开。

### 1.2 网络要求

- 安卓设备与对端必须在**同一个局域网**（同一路由器 / 同一网段）
  - 一台设备开热点、另一台连上这个热点 → 属于同一网段，也可以
  - 两台设备各连各的网络（没有共同路由器）→ **互相发现不了**。
    华为分享在这种情况下靠 BLE 引导 + Wi-Fi Direct 直连，本项目暂未实现 P2P 直连
- 端口：**TCP 5684**（传输）、**UDP 5684**（设备发现）
- 公司网络 / 访客 Wi-Fi 常开「AP 隔离」，设备之间互相不可见，这种网络用不了
- 安卓端用的是**组播 + 广播双通道**发现，个别机型对组播过滤较严，扫描不到时先看本机 IP 是否同网段

### 1.3 权限

| 权限 | 用途 | 不给会怎样 |
|---|---|---|
| `INTERNET` / `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` | 收发数据、读 Wi-Fi 状态 | 无法使用 |
| `CHANGE_WIFI_MULTICAST_STATE` | 收设备发现用的**组播包** | 可能搜不到对端（广播仍可用） |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_DATA_SYNC` | 后台监听接收 | 后台很快被杀，收不到分享 |
| `POST_NOTIFICATIONS`（Android 13+） | 显示前台服务通知 | 不给也能跑，但看不到常驻通知 |
| `WAKE_LOCK` | 传输过程中避免 CPU 休眠 | 大文件可能变慢或中断 |

安装后首次打开会弹通知权限申请；**组播锁**由前台服务自动持有，不需要用户手动开。

## 二、安装

### 2.1 直接装 APK

1. 把 `app-debug.apk`（调试版）或 `app-release.apk`（**已签名的正式版**）传到手机
2. 用文件管理器点击安装；首次需要在系统里允许「安装未知来源应用」
3. 桌面出现 **海因分享** 图标

> 调试版包名是 `com.heinshare.app.debug`，和正式版 `com.heinshare.app` 可以共存。
> 正式版已签名，可直接安装；后续升级必须用同一把密钥（见 [`构建说明.md`](构建说明.md) 第四节）。

## 三、怎么用

### 3.1 主界面

打开 App 后从上到下依次是：

| 区域 | 说明 |
|---|---|
| **状态行** | 本机局域网地址、当前是「空闲」还是「正在接收」、本机显示名 |
| **接收文件（保持后台监听）** | 打开后启动前台服务，开始**发现对端**并监听 5684 端口 |
| **发送文件到设备…** | 进入发送界面 |
| **接收记录** | 查看本次会话收到的文件清单 |
| **附近设备** | 扫描到的对端列表（名称、IP、类型），点一下即可选为发送目标 |
| **运行日志** | 协议级日志，发现/握手/传输每一步都打在这里，排查问题先看它 |

**接收开关一定要打开**，否则只能发不能收。

### 3.2 发文件给对端

1. 主界面点「发送文件到设备…」
2. 选文件：点「选择文件」可多选；点「选择文件夹」会**保留目录结构**整目录发送
3. 从下拉框里选一个对端（就是「附近设备」列表里的那台）
4. 点「开始发送」，进度条实时走，完成后提示「发送完成：N 个文件，X 字节」

> 文件是通过系统文件选择器（SAF）授权读取的，App **不会**申请存储权限，也不会读到你没选过的文件。

### 3.3 接收对端发来的文件

1. 保持主界面的「接收文件」开关打开
2. 对端发起分享后，安卓这边弹出**接收界面**（也可以从通知栏进入）
3. 点「接受」或「拒绝」（默认 25 秒不操作自动拒绝）
4. 接受后开始落盘，界面显示进度；完成后在「接收记录」里能看到清单
5. 在「**记录**」页下半部分的「**已接收的文件**」里，**点任意一行可以直接打开那个文件**

### 3.4 收到的东西放在哪

位置在**设置 → 接收目录**里改，三选一：

| 选项 | 落点 | 说明 |
|---|---|---|
| 应用私有目录（默认） | `/storage/emulated/0/Android/data/com.heinshare.app/files/Heinshare/` | 不需要任何存储权限 |
| 系统「下载」目录 | `内部存储/Download/Heinshare/` | Android 10+ 用 MediaStore 写入，无需权限；文件在系统「文件」App 里直接可见 |
| 选择其他位置… | 用户指定目录 | 调起系统目录选择器（SAF），可自己挑「下载」「文档」或任意目录 |

- 目录结构按对端发来的路径原样保留，**重名文件自动加后缀**（`a (1).txt` 这种），不会覆盖
- 接收中的临时文件以 `.part` 结尾，转正后自动去掉后缀
- 应用私有目录属于 App 私有外部目录：Android 11+ 上普通文件管理器默认不显示 `Android/data`
  - 查看方式：系统「文件」App → 内部存储 → `Android` → `data` → `com.heinshare.app` → `files` → `Heinshare`
  - 或用支持访问 `Android/data` 的第三方文件管理器
  - 或用 `adb`：`adb shell ls /sdcard/Android/data/com.heinshare.app/files/Heinshare`

> 选「系统「下载」目录」后，收到的文件会直接出现在系统下载目录里，路径为 `下载/Heinshare/`。
> Android 9 及以下写公共目录需要 `WRITE_EXTERNAL_STORAGE` 权限（App 已声明，仅该版本需要运行时授权）。

## 四、和 Windows 版对传

安卓端和 Windows 端是**对等的两端**，可以互发：

| 方向 | 说明 |
|---|---|
| Windows → 安卓 | Windows 端选文件发给安卓，安卓这边确认接收 |
| 安卓 → Windows | 安卓选文件发给 Windows，Windows 弹出确认框（否在左、是在右） |

两端同时开着一个即可，**不需要配对、不需要登录、不走云端**。

## 七、常见问题

---

**Q：附近设备一直是空的？**

1. 确认对端已打开「华为分享 / 鸿蒙星河互联」并停在接收页
2. 确认同一网段：看主界面顶部的「本机地址」，和电脑 `ipconfig` 的 IPv4 前三段一致
3. 关掉手机的「AP 隔离」类功能（路由器上）
4. 部分机型省电模式会杀掉组播：把 App 的电池策略设为「不限制」
5. 看日志里有没有 `发现` 相关记录——有包说明网络通，只是对端没回

**Q：能发现但连不上？**

看日志里卡在哪一步：`TCP 连接` / `认证` / `能力协商` / `挑战`。多数是对端页面已经退出了，重新让对端打开接收页。

**Q：文件传到一半断了？**

大文件传输期间不要让手机息屏或切走；前台服务通知不要被「电池优化」杀掉。

**Q：和 iPad / iPhone 对不上？**

Apple 通道走的是 ChaCha20-Poly1305 加密 + `phone_exact` 档位的 SETTINGS 帧，
密码套件协商不对称（两端规则不同），Android 端的做法是「多套件依次尝试 + 明文兜底」。

**Q：能同时和几台设备互传？**

接收侧一次只处理一个分享请求；发送侧可以给不同设备分别发。

## 八、日志怎么读

日志是纯文本，每行一个时间戳，主要关键字：

| 关键字 | 含义 |
|---|---|
| `发现` / `peer` | 设备发现，收到了对端的 beacon |
| `TCP` / `accept` | TCP 连接建立 |
| `认证` / `信封` / `公钥` / `挑战` | 握手四步 |
| `SETTINGS` / `caps` | 密码套件协商 |
| `清单` / `manifest` | 文件清单交换 |
| `DONE` | 传输结束 |

排查问题优先看这几类关键字。
